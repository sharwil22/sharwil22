## 🚀 Featured Projects

### 🤟 Real-Time Indian Sign Language Recognition
Real-time ISL detection for the Deaf and hard-of-hearing community, using MediaPipe Holistic and a GRU sequence classifier, with an agentic Gemini function-calling fallback layer for robust sentence assembly on low-confidence predictions. Built on a real, signer-independent dataset collected with a partner organization. Targeting a Q1 journal publication.

**Tech:** Python · MediaPipe · GRU · Deep Learning · Gemini Function-Calling
🔗 [View Project](https://github.com/sharwil22/sign-language-detection-isl)

### 💳 Failed-Subscription Revenue Recovery Agent
Built for the **Razorpay AI Buildathon 2026** — an agentic AI system that diagnoses failed UPI/card subscription payments and autonomously selects recovery actions via Gemini function-calling. Implements pay-cycle-aware retries and escalating multi-channel notifications (calls, SMS, email) under bounded, auditable decision logic. Achieved **75.7% recovery vs. 57.1%** for a naive baseline across 140 synthetic cases (₹79.8K vs. ₹61.6K recovered). Shipped with a live Streamlit dashboard for batch metrics, per-case audit trails, and reasoning logs.

**Tech:** Python · Gemini Function-Calling · Agentic AI · Streamlit

### 🔧 Autoregent: Self-Healing API Gateway
Built for the **Gemini X Express Hackathon 2026** — a FastAPI gateway that uses Gemini to diagnose and remediate schema drift live, with AI-assisted healing enforced only on eligible read-path routes. Guards include confidence thresholds, timeouts, unrecoverable-drift detection, loop detection, per-route circuit breakers, and heal budgets. HMAC-signed disclosure events feed a real-time Next.js dashboard. Deployed end-to-end on Railway.

**Tech:** Python · FastAPI · Gemini · Next.js · Agentic AI
